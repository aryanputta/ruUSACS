# RUParked

# RUParked is a mobile app for Rutgers University students, designed to reduce friction for commuters and make it easier to get to class on time. The app focuses on convenience and planning, providing real-time parking information and predictive tools so students don’t miss class due to parking stress.

# Features

# Dashboard – Live campus parking map with clickable lots, spot-level availability, and Smart Suggestions for recommended parking.
# Time Travel – Predictive parking forecasts starting at the current time, updated every 15 minutes up to an hour ahead.
# Schedule Integration – Links your class schedule to the nearest parking lot with availability forecasts for each class.
# Social Feed – Real-time student updates on parking, closures, and congestion, with likes, comments, and trending topics.
# Friends System – Search for and add friends, prioritizing updates from trusted peers.
# Themes – Universal mode for a clean interface, optional retro-inspired mode, dark backgrounds, and Rutgers Red accents.
